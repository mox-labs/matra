# Conventions survey, 2026-09-05

A read-only survey of exemplar open-source packages, CLIs, and developer tooling, run to ground [ADR-0011](../decisions/0011-out-of-the-box.md) and the I10 and I11 plans. Every exemplar cell carries a URL or `local: <cmd>` (output run on the maintainer's machine); every matra cell is a `file:line` read the same day. Absences were established by `find` and `grep`, not memory. Second-hand claims are flagged as such.

## Warrant

Verified by reading in this repo: `src/bin/matra.rs` in full; `src/nlp/udpipe.rs:18-100` plus a grep of its env, download, and hash surface; `python/matra/cli.py` in full; `python/matra/__init__.py:1-40`; `Cargo.toml`, `pyproject.toml`, `book/book.toml`, `book/src/SUMMARY.md`, `book/src/guides/cli.md:1-50`, `spec/README.md`, `justfile`, `.mise.toml`, `README.md`, `.claude/skills/aces/SKILL.md` frontmatter. Absences by `find` and `grep`: no `llms.txt`, `AGENTS.md`, `CITATION.cff`, `$schema`, `NO_COLOR`, `clap_complete`, stdin handling, or `references/` under `.claude/skills/`.

Verified by running locally: ripgrep 15.1.0, jq 1.8.1, cargo 1.95.0, gh 2.83.1, uv 0.9.13, ollama 0.13.0, ruff 0.16.6 via `uvx`; presence of `~/.config/gh`, `~/.cargo`, `~/.rustup`, `~/.ollama/models`, `~/.cache/huggingface/hub`; absence of `~/.config/uv`, `~/Library/Application Support/uv`, `~/.cache/ruff`.

Verified by fetching: every URL above except those flagged. 404s recorded as findings: `llms.txt` on polars and spaCy; `AGENTS.md` on polars, spaCy, stanza, vercel/next.js, cli/cli; no `CITATION.cff` at stanza's or UDPipe's expected paths.

Second-hand only (search synthesis, not a primary fetch): rustfmt's compiled-in defaults wording; ruff's SARIF conformance; the `gh skill` changelog; fabric's `patterns/` layout; aider's config conventions.

What sources declined to claim: llmstxt.org calls itself "a proposal to standardise", not a standard. Cargo extends "stable and versioned" only to `cargo metadata --format-version`, not to `--message-format=json`. ripgrep's `--json` help states no stability promise. maturin argues against bin plus cdylib in one wheel rather than merely lacking it. Ollama's sha256 verification is evidenced by error text in issues, not by a docs page. Cargo publishes no exit-code table.

The single most consequential finding: across uv, ruff, gh, jq, cargo, ollama, `llm`, aider, fabric, sgpt, just, mise, stripe, vercel, wrangler, bun, and deno, exactly one tool, Vercel Labs' `agent-browser`, prints its own agent-facing instructions from the CLI with a second tier of drill-down. Everything else is a static file, a skill package manager, or an MCP server. The convention is essentially unestablished, with one precedent whose stated rationale is version coherence: instructions that match the installed binary rather than a cached copy.
