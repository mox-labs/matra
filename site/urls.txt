# The published URL contract of https://mox-labs.github.io/matra/.

# Every path here is cited somewhere a reader or an agent may follow it from:
# Cargo.toml, CITATION.cff, README.md, llms.txt, bookmarks, other sites. Each
# must keep resolving. scripts/check-url-manifest.sh checks the list three ways:
#
#   --build site/build   gate 7 of the docsite floor: every path the site build
#                        writes (all but api/) exists, and every page, Markdown
#                        twin and text file the build writes is listed here
#   --dir _site          docs.yml, before upload: every path, rustdoc included
#   --live <url>         docs.yml, after deploy: every path answers 200
#
# A new page adds its .html and .md lines here. Removing or renaming a path
# breaks a published URL; keep a page at the old path instead.
#
# Paths are relative to the site root. api/ is rustdoc, added at deploy.
